# 대시보드와 시각화

로그인하면 열리는 홈 화면이 **대시보드**입니다. 원하는 지표 차트(시각화)를
만들어 대시보드에 배치해 두면, 여러 캠페인의 현황을 한 화면에서 볼 수
있습니다. 대시보드는 팀 전체가 공유하므로 팀이 같은 화면을 보게 됩니다.

![대시보드](/img/claire/dashboard.png)

## 대시보드 다루기

- 사이드바 **개요 → 대시보드**를 누르면 내 기본 대시보드가 열립니다.
  팀에서 처음 만든 대시보드가 **기본값**이 되고, 목록에서 다른
  대시보드를 기본값으로 지정하면 나만의 기본 대시보드로 바뀝니다. 대시보드가
  하나도 없으면 목록이 "데이터 없음"으로 보이니 [새 대시보드]로 먼저 만드세요.
- 대시보드 상단의 [모든 대시보드]에서 대시보드 목록을 보고, [새 대시보드]로 새
  대시보드를 만듭니다 (이름 필수, 설명 선택). 목록은 **내 대시보드**(내가 만들었거나
  북마크했거나 기본값으로 쓰는 대시보드)와 **모든 대시보드**(팀 전체) 탭으로 나뉘고,
  **북마크** 별 아이콘으로 자주 보는 대시보드를 내 대시보드에 올려 둘 수 있습니다.
- [사용자 지정]을 누르면 편집 모드가 됩니다. 만들어 둔 시각화를 검색해 위젯으로
  올리고, 손잡이를 끌어 위치를 옮기거나 우하단 모서리로
  크기를 조절한 뒤 레이아웃을 저장합니다. 위젯은 별도 확인 없이 바로
  삭제되니 주의하세요.
- 대시보드 자체는 삭제할 수 없고 위젯만 뺄 수 있습니다. 레이아웃 편집은
  데스크톱 폭에서만 가능하며, 좁은 화면에서는 위젯이 세로로 쌓여 보기만 됩니다.
- 상단 **기간 선택**(기본 최근 24시간)은 모든 위젯에 함께 적용되고 브라우저에
  저장됩니다. 지표 수집이 하루 한 번인 캠페인만 있다면 "최근 24시간"에는
  "선택 기간에 데이터가 없습니다. 기간을 넓혀 보세요."가 보일 수 있으니 최근 기간 탭에서
  최근 1주·1개월 등으로 넓혀 보세요. 제목에 "(최근 90일)"처럼 기간이 붙은 위젯은
  시각화에 고정된 자체 기간을 쓰기 때문에 상단 기간 선택을 따르지 않으며, 기간
  선택 옆에 그런 위젯이 있다는 표시가 붙습니다.

![대시보드 목록](/img/claire/dashboards-list.png)

목록 상단 [JSON 가져오기]로 내보내 둔 대시보드 정의를 붙여 넣으면 새 대시보드와
그 안의 시각화가 함께 만들어집니다.

## 시각화 만들기

**개요 → 시각화**에서 [새 시각화]를 누르면 왼쪽에 미리보기,
오른쪽에 설정 패널이 있는 편집기가 열립니다. 오른쪽 설정을 바꾼 뒤
[미리보기 적용]으로 미리보기를 갱신하고, 미리보기 위의 **필터**와
기간을 바꿨을 때는 [새로고침]으로 갱신합니다. 저장은 [시각화 생성]입니다.

![시각화 편집기](/img/claire/visualization-editor.png)

**데이터 탭**에서 정하는 것들:

| 항목 | 설명 |
|---|---|
| **제목** | 시각화 이름 |
| **시각화 유형** | 날짜 히스토그램(시계열) · 원형 · 히트맵 · 게이지 · 지표(단일 숫자) · 표 |
| **지표** | [지표 추가]로 기본 지표(Raw metric) 또는 수식(Formula)을 고릅니다. 최대 2개, 게이지·지표는 1개 |
| **버킷** | X축(날짜 및 시간 또는 지표)과 시리즈 분할(플랫폼 · 캠페인 그룹 · 캠페인 중 하나)로 시리즈를 나눕니다 |
| **최소 간격** | 시계열의 최소 집계 단위 (`auto`, `1h`, `1d`, `1w`, `1M` 등). auto는 기간에 맞춰 자동 선택 |

미리보기 바로 위에는 **필터**(어떤 캠페인을 집계할지 좁히는 조건식, 아래 참고)와
기간 선택, [새로고침] 버튼이 따로 놓여 있습니다.

표는 X축 값(날짜 또는 지표)을 행, 시리즈를 열로 펼친 표입니다. 행은
X축 값 오름차순으로 고정이고 열 구성이나 정렬을 따로 설정하는 항목은 없습니다.
팀 첫 화면의 기본 대시보드에 있는 안내 문구 위젯(Markdown)은 시스템이
넣는 것이라 직접 만들거나 편집할 수 없고, 위젯 추가 목록에도 나오지 않습니다.

**지표 및 축 탭**은 단위 표기(`KRW {VALUE}`처럼 `{VALUE}` 포함),
합계/평균/최신값 집계, 차트 모양(영역·막대·선, 누적, 백분율)을,
**패널 설정 탭**은 범례·툴팁·색상 팔레트·임계선을 정합니다.

지표 유형을 고르면 지표 및 축 탭 맨 위에 **표시 모드**가 나타납니다.

| 표시 모드 | 결과 |
|---|---|
| **일반** | 값 하나를 그대로 보여주는 기본 형태 |
| **비교 카드** | 현재 값과 비교 대상을 나란히 놓는 KPI 카드 |

비교 카드를 고르면 **비교 대상**이 따라 나옵니다. 없음, 이전 기간(직전 같은 길이
구간), KPI 목표(캠페인 KPI 목표) 중에서 고르며, KPI 목표는 대상 목표를 지정합니다.
표시 모드를 일반으로 되돌리면 설정해 둔 비교는 지워집니다.

**KPI 목표는 대상 캠페인이 하나로 정해진 편집기에서만 고를 수 있습니다.**
캠페인 상세 대시보드에서 만든 시각화가 여기에 해당합니다. 개요 →
시각화에서 새로 만들 때나 캠페인 그룹 대시보드에서 차트를 만들 때는
대상 캠페인이 하나로 좁혀지지 않아 이 선택지가 잠깁니다. 그룹 대시보드에
KPI 카드를 올리려면 시각화 추가의 **KPI 지표**를 쓰세요. 캠페인이
정해져 있어도 고른 지표와 원천 지표가 같은 KPI 목표만 후보로 나옵니다.

미리보기 상단의 기간 선택은 **최근 24시간 · 지난주 · 지난달 ·
최근 3개월** 네 가지이며 기본은 최근 3개월입니다. 기간과 필터를 바꿨을
때는 옆의 [새로고침]으로, 오른쪽 설정 패널을 바꿨을 때는 [미리보기 적용]으로
미리보기를 다시 그립니다. 저장은 아래쪽 [시각화 생성] 또는
[변경사항 저장]으로 합니다. 편집 중인 설정은
주소(URL)에 담기므로 링크를 복사해 동료에게 그대로 보여줄 수 있습니다.

### 필터 조건식

필터 검색창에 **검색할 항목과 조건**을 입력하면 원하는 데이터만 볼 수 있습니다. 입력 중에는 사용 가능한 필드와 값이 자동 완성됩니다.

```text
campaign.name: "가을 프로모션"
```

- `campaign.name`: 검색할 항목
- `:`: 일치 조건
- `"가을 프로모션"`: 찾을 값

#### 검색할 수 있는 항목

| 필드 | 설명 |
|---|---|
| `platform` | 플랫폼 |
| `campaign.code` | 캠페인 코드 |
| `campaign.name` | 캠페인 이름 |
| `campaign.status` | 캠페인 상태 |
| `campaign_group.code` | 캠페인 그룹 코드 |
| `campaign_group.name` | 캠페인 그룹 이름 |
| `campaign.budget.daily` | 캠페인 일일 예산 상한 |
| `campaign.budget.total` | 캠페인 총예산 |
| `campaign.period.start` | 캠페인 시작 시각 |
| `campaign.period.end` | 캠페인 종료 시각 |

#### 값 일치: `:`

입력한 값과 일치하는 항목을 찾습니다. 영문 대소문자는 구분하지 않으며, 값에 공백이 있으면 큰따옴표로 감싸주세요.

```text
campaign.code: 18597463
campaign.name: "가을 프로모션"
```

#### 일부 일치와 값 존재 여부: `*`

`*`는 임의의 문자열을 뜻합니다. 단독으로 사용하면 값이 존재하는 항목을 찾습니다.

| 조건 | 의미 |
|---|---|
| `campaign.name: 가을*` | 이름이 “가을”로 시작 |
| `campaign.name: *프로모션` | 이름이 “프로모션”으로 끝남 |
| `campaign.name: *할인*` | 이름에 “할인”이 포함됨 |
| `campaign_group.code: *` | 캠페인 그룹 코드가 존재함 |

#### 조건 조합: `AND`, `OR`, `NOT`

| 연산자 | 의미 |
|---|---|
| `AND` | 모든 조건을 만족 |
| `OR` | 하나 이상의 조건을 만족 |
| `NOT` | 해당 조건을 제외 |

다음은 Google Ads 캠페인 중 일일 예산 상한이 100,000 이상인 항목을 찾습니다.

```text
platform: google_ads AND campaign.budget.daily >= 100000
```

같은 필드의 여러 값은 괄호 안에서 `OR`로 연결할 수 있습니다. 아래 두 표현은 같은 의미입니다.

```text
campaign.name: "가을 행사" OR campaign.name: "겨울 행사"
campaign.name: ("가을 행사" OR "겨울 행사")
```

다음은 이름에 “테스트”가 들어간 캠페인을 제외합니다.

```text
NOT campaign.name: *테스트*
```

#### 조건 묶기: 괄호

괄호 안의 조건을 먼저 판단합니다. 괄호가 없으면 **NOT → AND → OR** 순서로 처리합니다.

다음은 이름에 “가을” 또는 “겨울”이 포함된 Google Ads 캠페인을 찾습니다.

```text
(campaign.name: *가을* OR campaign.name: *겨울*) AND platform: google_ads
```

#### 숫자와 날짜 비교

| 연산자 | 숫자 비교 | 날짜 비교 |
|---|---|---|
| `>` | 기준값보다 큼 | 기준 시각 이후, 기준 제외 |
| `>=` | 기준값 이상 | 기준 시각 이후, 기준 포함 |
| `<` | 기준값보다 작음 | 기준 시각 이전, 기준 제외 |
| `<=` | 기준값 이하 | 기준 시각 이전, 기준 포함 |

숫자에는 쉼표나 통화 기호를 넣지 않습니다.

```text
campaign.budget.total >= 1000000 AND campaign.budget.total < 5000000
```

날짜와 시간은 큰따옴표로 감싸고 시간대를 지정합니다. 다음은 한국 시간 기준 2026년 9월 1일 0시부터 시작하는 캠페인을 찾습니다.

```text
campaign.period.start >= "2026-09-01T00:00:00+09:00"
```

#### 입력 시 주의사항

- 여러 값은 쉼표가 아닌 `OR`로 연결합니다. `IN`은 지원하지 않습니다.
- 일치 조건은 `=` 대신 `:`, 제외 조건은 `!=` 대신 `NOT`을 사용합니다.
- `AND`, `OR`, `NOT`은 소문자로 입력해도 됩니다.
- 검색창을 비우면 추가 필터 조건이 해제됩니다.

### 시각화 목록과 수정 권한

**개요 → 시각화** 목록은 이름 · **사용 가능 범위** · **유형** ·
**최근 수정** 열로 이뤄지며, 각 열 머리글을 눌러 정렬할 수 있습니다.

![시각화 목록](/img/claire/visualizations.png)

**사용 가능 범위**는 이 시각화를 어디에 올릴 수 있는지를 나타냅니다.

- **모든 대시보드** — 아무 대시보드에나 위젯으로 올릴 수 있습니다.
- **캠페인 제한** — KPI 목표에 묶인 시각화입니다. 이름 아래에 묶인
  캠페인 이름이 함께 표시됩니다.

직접 고르는 항목이 아니라 **비교 대상에 KPI 목표를 지정했는지**에 따라
자동으로 정해집니다.

:::tip
차트 설정을 고치려면 목록에서 **시각화 이름을 클릭**해 편집기로 들어갑니다.
행 메뉴(⋮)의 [수정]은 이름만 바꾸는 창입니다. 수정은 만든 사람 또는 팀 수정 권한이
있는 사람만 할 수 있고, 행 메뉴의 [삭제]로 지울 수 있습니다.
행 메뉴의 [JSON 내보내기]로 시각화 정의를 내보낼 수 있고, 상단 ⋮ 메뉴의
[JSON 가져오기]로 가져옵니다. 가져오기는 시각화 작성 권한이 있어야 보입니다.
:::

## 캠페인·캠페인 그룹 대시보드

팀 공용 대시보드와 별개로, **캠페인 상세**와 **캠페인 그룹 상세**의 대시보드
탭은 그 캠페인(그룹)만을 위한 대시보드입니다. 처음에는 KPI 카드와 성과 추이
차트가 기본 구성으로 보이고([성과 확인](/claire/performance#캠페인-대시보드--kpi와-성과-추이)),
캠페인은 [대시보드 사용자 지정], 그룹은 [사용자 지정]을 누르면
기본 구성이 실제 위젯으로 저장되면서 편집 모드가 열립니다.

- 편집 모드의 시각화 추가에서 **시각화**(이 캠페인·그룹의 지표로
  새 차트 만들기) 또는 **KPI 지표**(설정된 KPI 목표를 현재·직전 값과 함께
  카드로 추가)를 고릅니다. 팀 공용 시각화 목록에서 골라 넣는 방식은 아닙니다.
- 이 대시보드의 시각화는 범위가 해당 캠페인·그룹으로 고정되어 편집기의 필터
  칸이 읽기 전용입니다. 그룹 대시보드의 KPI 카드는 그 캠페인이 그룹에서 빠지면
  빈 값으로 표시됩니다.
- 캠페인(그룹)당 대시보드는 하나이며, 배치 편집에는 해당 캠페인(그룹)과
  대시보드의 수정 권한이, 시각화 추가에는 시각화 작성 권한이 추가로 필요합니다. 북마크·기본 대시보드 지정은 팀 공용 대시보드에만 있습니다.
