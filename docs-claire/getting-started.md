# 시작하기

## 로그인

[claire.infinit-c.com](https://claire.infinit-c.com)에 접속해 이메일/비밀번호 또는
Google 계정으로 로그인합니다. 계정은 팀(조직) 단위로 발급되니, 이미 팀이 있다면
팀 관리자에게 초대를 요청하세요.

![로그인 화면](/img/claire/login.png)

### 조직(팀) 새로 만들기

아직 팀이 없다면 로그인 화면의 **조직 만들기**에서 직접 만들 수 있습니다.
(가입 화면에서는 "조직", 로그인 후 설정 화면에서는 "팀"으로 부르지만 같은 단위입니다.)

1. **회사 이메일 입력** — Google Workspace 등 회사 도메인 이메일을 넣고
   [이메일로 계속]을 누릅니다. gmail.com · naver.com · daum.net 같은
   개인 메일 도메인으로는 만들 수 없고, 한 도메인당 팀은 하나만 만들 수
   있습니다.
2. **이메일 인증** — 받은 메일의 인증 링크를 **24시간 안에** 누릅니다.
3. **조직 설정 위저드** — 조직 이름, 관리자 이름, 비밀번호(8자 이상)를 정하고
   [조직 만들기]를 누르면 팀과 관리자(root) 계정이 함께 만들어지고
   바로 로그인됩니다. 이어지는 Slack 연동과 매체 연동 단계는 [나중에 하기]로
   건너뛰고 나중에 해도 됩니다.

## 화면 구성

로그인하면 기본 대시보드가 열립니다. 좌측 사이드바가 전체 메뉴입니다.

| 메뉴 | 하는 일 |
|---|---|
| **내 채팅** | 내가 Claire와 나눈 대화 목록 |
| **개요 → 대시보드 / 시각화** | 지표 차트를 모아 보는 홈 대시보드와 차트 만들기 |
| **운영 → 캠페인 → 캠페인 그룹 / 캠페인** | 광고주 그룹과 캠페인 관리 |
| **운영 → 채팅** | 팀 전체의 대화 목록 |
| **목표 → 지표 분류 / 수식 / KPI 규칙** | 지표·수식·KPI 규칙 |
| **모니터링 → 보고서 / 맞춤 요약** | 엑셀·CSV 보고서, 정기 성과 요약 발송 |
| **모니터링 → 알림 / 알림 기록** | 알림 규칙과 발생 이력 |
| **설정** | 팀 설정, 매체 연동(플랫폼 연동), 알림 채널(알림 채널 그룹) |
| **보안** | 정책·사용자 그룹·사용자 관리 (관리자용), API 키 |

사이드바 메뉴는 계정 권한에 따라 구성되므로 사람마다 보이는 항목이 다를 수
있습니다. 우측 상단에는 검색, 알림, 다크/라이트 모드 전환, 언어(지구본),
**팀 전환** 메뉴와 계정 메뉴(내 프로필·로그아웃)가 있고, 첫 접속 시 화면 모드는
OS 설정을 따릅니다. 여러 팀에 속한 계정은 팀 전환 메뉴에서 작업할 팀을 고릅니다.

계정 메뉴 → **내 프로필**에서 언어(한국어·English), 시간대, 강조 색상을 바꿀 수
있습니다. 시간대는 기본 Asia/Seoul이며, 화면의 모든 날짜·시간과 기간 선택이 이
설정을 따릅니다 (브라우저별로 저장).

## 첫 캠페인 연결까지

처음 쓰는 팀이라면 이 순서로 진행하세요.

1. **캠페인 그룹 만들기** — 광고주나 브랜드 단위 묶음을 먼저 만듭니다. → [캠페인 연결](/claire/campaigns)
2. **매체 연동** — 설정 → 플랫폼 연동에서 매체 플랫폼을 연동하고, 광고 계정과 캠페인을 불러옵니다.
3. **성과 수집** — 캠페인 상세 우상단 메뉴(⋮)의 [지금 수집]으로 성과 데이터를 수집합니다. → [성과 확인](/claire/performance)
4. **Claire에게 질문** — 우하단 채팅 버튼을 눌러 성과에 대해 물어봅니다. → [Claire와 대화하기](/claire/chat)
5. **대시보드 구성** — 자주 보는 지표를 차트로 만들어 홈 화면에 배치합니다. → [대시보드와 시각화](/claire/dashboards)
