# 자주 묻는 질문

### 성과 데이터가 안 쌓여요

순서대로 확인해 보세요.

1. **수집 단위** — 캠페인의 지표 집계(수집 단위)가 캠페인이 아니면 Meta ·
   Google Ads · SA360 · Kakao Moment는 수집을 건너뜁니다. 캠페인 수정에서 확인하세요.
2. **연동 상태** — 캠페인이 `연결 해제됨`이라면 플랫폼 연동이 해제된 것입니다.
   플랫폼 연동에서 재연동하세요. 연동 상태가 **재인증 필요**라면 매체 인증이
   만료된 것이니 [재인증]으로 다시 인증하세요.
3. **수집 시점** — 자동 수집은 캠페인에 설정된 주기(1시간~24시간)로 돌고
   어제부터 오늘까지의 데이터를 가져옵니다. 방금 등록한 캠페인이라면 상세
   메뉴(⋮)의 [지금 수집]으로 원하는 기간을 직접 수집하는 게 빠릅니다.

### Google 연동 중 패스키 인증이 휴대폰으로 넘어가서 계속 실패해요

2026년 8월부터 Google Ads·API 로그인에 패스키가 의무화되면서 생기는 현상입니다. 회사
Workspace 계정은 관리자가 조직 단위로 "비밀번호 없이 로그인"을 해제해야 비밀번호로
진행할 수 있습니다. → [매체 연동이 안 될 때](/claire/campaigns#매체-연동이-안-될-때--플랫폼별-점검)

### 대시보드에 "선택 기간에 데이터가 없습니다"만 보여요

기간 선택이 기본값 "최근 24시간"인데 지표 수집이 하루 한 번이거나 캠페인이
끝난 경우입니다. 기간 버튼 → 최근 기간 탭에서 최근 1주·1개월 등으로 넓혀
[적용]하세요. 설정은 브라우저에 저장됩니다.

### 과거 데이터를 여러 캠페인에 한꺼번에 다시 받고 싶어요

캠페인 목록에서 체크박스로 캠페인을 고르고 **작업 → 선택 캠페인 재수집**을
쓰면 같은 기간을 한 번에 요청할 수 있습니다. 고른 캠페인이 모두
활성 상태이고 매체에 연결돼 있어야 이 메뉴가 눌립니다. → [여러 캠페인 한꺼번에 다시 수집하기](/claire/performance#여러-캠페인-한꺼번에-다시-수집하기)

### 캠페인(또는 알림)이 삭제가 안 돼요

활성 상태에서는 삭제할 수 없습니다. 먼저 **비활성화**하면 삭제
버튼이 나타납니다.

### 알림이 안 와요

- 알림 규칙의 **받는 사람에 알림 채널 그룹이 지정돼 있는지**, 그 그룹에 채널
  (이메일·Slack)이 실제로 추가돼 활성 상태인지 확인하세요. 알림 기록의 전달 열이
  "채널이 없습니다"라면 그룹에 채널이 없는 것입니다.
- Slack 비공개 채널은 봇을 먼저 초대해야 발송됩니다.
- 연속 횟수를 2 이상으로 설정했다면 조건을 연속으로 그만큼 위반해야
  발생합니다. 위반이 지속되는 동안의 반복 알림은 설정한 간격(기본 1시간)을
  따릅니다.
- 알림 목록의 상태가 **데이터 없음**이라면 집계 구간에 데이터가 없어 판정을 건너뛴
  것입니다. 집계할 최근 시간이 매체 데이터 단위나 수집 주기에 비해 너무 짧지
  않은지 확인하고, 행 메뉴의 [평가 기록]에서 실제 평가 구간과 값을 보세요.
- [지금 수집]으로 수동 수집하면 그 자리에서 알림을 평가하지는 않습니다. 5분마다
  도는 정기 평가에서 확인 주기가 지난 규칙부터 반영됩니다.

### 알림 규칙을 고쳤더니 상태가 초기화됐어요

의도된 동작입니다. 규칙을 수정하면 위반·복구 카운트가 리셋되고 다음
평가부터 새로 셉니다.

### 시간이 실제와 다르게 표시돼요

화면의 날짜·시간은 **내 프로필**의 시간대 설정을 따릅니다 (기본
Asia/Seoul, 브라우저별 저장). 다른 PC에서 다르게 보인다면 그쪽 설정을 확인하세요.

### 채팅을 열었더니 이어갈지 새로 시작할지 물어봐요

같은 화면에서 이전에 나눈 대화가 있으면 **기존 채팅 이어가기**와 **새로운
채팅** 중 고르게 됩니다. 새 주제라면 새로운 채팅을 고르세요. 이전 대화는
내 채팅에 그대로 남습니다.

### 캠페인 목록에서 검색창이 없어졌어요

검색과 상태·그룹 드롭다운이 하나의 필터 칸으로 합쳐졌습니다. `campaign.name:
*브랜드*` 처럼 조건식을 쓰고 [적용]을 누르세요. 문법은
[캠페인 관리](/claire/campaigns#캠페인-관리)에 있습니다.

### 캠페인 목록에 내 캠페인만 보여요 (또는 남의 캠페인까지 보여요)

우측 상단의 **내 데이터 / 팀 전체** 전환을 확인하세요. 내 데이터는 내가 연동한 매체
계정의 캠페인만, 팀 전체는 팀의 모든 캠페인을 보여줍니다.

### 화면에 어떤 메뉴가 안 보여요

사이드바 메뉴는 계정 권한에 따라 구성됩니다. 필요한 메뉴가 없다면 팀
관리자에게 권한(정책)을 요청하세요.

### 다른 팀(조직) 화면으로 바꾸고 싶어요

여러 팀에 속한 계정이면 우측 상단 **팀 전환** 메뉴에서 팀을 고릅니다. 회사
최상위 관리자는 계정 메뉴의 **회사 설정**에서 팀을 만들고 구성원을 관리합니다.

### 클라이언트에게 성과를 보여 주고 싶은데 Claire 계정이 없어요

캠페인·그룹 상세의 [보고서 링크]로 읽기 전용 보고서 페이지 링크를 만들어 보내세요.
로그인 없이 만료일까지 열 수 있고, AI 채팅을 켜 두면 받는 사람이 보고서 숫자에 대해
하루 10개까지 질문할 수 있습니다. 링크 주소는 만들 때 한 번만 표시되니 바로 복사해
두세요. → [보고서 링크](/claire/report-links)

### 보고서 링크를 끊었는데 목록에 그대로 있어요

끊은 링크는 **끊김** 상태로 목록에 남고 받는 사람은 더 이상 열 수 없습니다. 목록에서
지우는 기능은 없으며, 다시 공유하려면 새 링크를 만드세요.

### 특정 화면이나 대화를 동료에게 공유하고 싶어요

- 열려 있는 탭 상태는 주소(URL)에 저장되므로 그대로 링크를 복사해 보내면
  됩니다. Claire 계정이 있는 동료라면 이 방법이 가장 빠릅니다.
- 캠페인 주소 뒤에 `?chat=open`을 붙이면 Claire 채팅이 열린 상태로
  진입합니다.
