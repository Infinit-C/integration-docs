# 자주 묻는 질문

### Trends에 데이터가 안 쌓여요

순서대로 확인해 보세요.

1. **수집 단위** — 캠페인의 Metric aggregation이 Campaign이 아니면 Meta ·
   Google Ads · SA360은 수집을 건너뜁니다. 캠페인 편집에서 확인하세요.
2. **연동 상태** — 캠페인이 `Disconnected`라면 플랫폼 연동이 해제된 것입니다.
   Platform Integrations에서 재연동하세요.
3. **수집 시점** — 자동 수집은 캠페인에 설정된 주기(1시간~24시간)로 돌고
   전일까지의 데이터를 가져옵니다. 방금 등록한 캠페인이라면 [Collect now]로
   원하는 기간을 직접 수집하는 게 빠릅니다.

### 캠페인(또는 알림)이 삭제가 안 돼요

활성 상태에서는 삭제할 수 없습니다. 먼저 **Disable**로 비활성화하면 삭제
버튼이 나타납니다.

### 알림이 안 와요

- 알림 규칙에 **Communication Group이 연결돼 있는지**, 그 그룹의 채널
  (이메일·Slack)이 활성 상태인지 확인하세요.
- Slack 비공개 채널은 봇을 먼저 초대해야 발송됩니다.
- 트리거 횟수를 2 이상으로 설정했다면 조건을 연속으로 그만큼 위반해야
  발생합니다. 위반이 지속되는 동안의 재알림은 쿨다운(기본 1시간) 간격을
  따릅니다.

### 알림 규칙을 고쳤더니 상태가 초기화됐어요

의도된 동작입니다. 규칙을 수정하면 위반·복구 카운트가 리셋되고 다음
평가부터 새로 셉니다.

### 화면에 어떤 메뉴가 안 보여요

사이드바 메뉴는 계정 권한에 따라 구성됩니다. 필요한 메뉴가 없다면 조직
관리자에게 권한(정책)을 요청하세요.

### 특정 화면이나 대화를 동료에게 공유하고 싶어요

- 열려 있는 탭 상태는 주소(URL)에 저장되므로 그대로 링크를 복사해 보내면
  됩니다.
- 캠페인 주소 뒤에 `?chat=open`을 붙이면 Claire 채팅이 열린 상태로
  진입합니다.
