# 성과 확인

## 성과 데이터 수집

캠페인 상세의 **Trends 탭**에서 [Collect now]를 누르면 수집할 날짜 범위를 선택하는
창이 뜹니다. 수집은 하루 단위로 처리되며, 요청 후 백그라운드에서 진행됩니다.

![성과 트렌드](/img/claire/campaign-trends.png)

수집이 완료되면 노출·클릭·전환·비용 등 지표의 일별 추이가 차트로 표시됩니다.
어떤 지표를 수집할지는 [지표와 KPI 규칙](/claire/targets)의 Metric Categories를 따릅니다.

:::info
정기 수집이 설정된 조직은 수동 수집 없이도 데이터가 자동으로 쌓입니다.
[Collect now]는 과거 기간을 소급 수집하거나 최신 데이터를 즉시 당겨올 때 사용하세요.
:::

## KPI 목표 설정

캠페인 상세의 **KPI 탭**에서 이 캠페인의 KPI 목표(Target)를 설정합니다.
[Edit]를 눌러 KPI 규칙(예: Minimum CTR, Maximum CPC)에 목표값을 입력하면,
수집된 성과가 목표 대비 어떤 상태인지 추적됩니다.

![캠페인 KPI 탭](/img/claire/campaign-kpi.png)

사용할 수 있는 KPI 규칙 목록과 커스텀 규칙은 [지표와 KPI 규칙](/claire/targets)을 참고하세요.
KPI 이탈 시 알림을 받으려면 [알림 규칙](/claire/settings#alerts--알림-규칙)을 설정하세요.
