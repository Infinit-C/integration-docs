# 캠페인 연결

Claire의 모든 기능은 캠페인이 연결돼 있어야 동작합니다. 캠페인은 두 단계
구조로 관리합니다. 광고주·브랜드 단위 묶음인 **캠페인 그룹** 아래에
매체의 실제 캠페인인 **캠페인**이 속하는 구조입니다.

## 캠페인 그룹 만들기

**운영 → 캠페인 → 캠페인 그룹**에서 [캠페인 그룹 생성]을 눌러 광고주나 브랜드 단위
그룹을 만듭니다. 마법사는 두 단계입니다.

1. **그룹 상세 정보** — 이름을 넣고 [계속]
2. **캠페인** — 아직 그룹이 없는 캠페인 중 포함할 것을 고르고 [캠페인 그룹 생성].
   캠페인을 하나도 고르지 않아도 빈 그룹으로 만들 수 있습니다.

같은 이름의 그룹이 이미 있으면 "같은 이름이나 값을 가진 항목이 이미 있습니다"
안내가 뜹니다.

![캠페인 그룹 목록](/img/claire/campaign-groups.png)

그룹 상세에는 탭이 세 개 있습니다.

- **대시보드** — 그룹 캠페인들의 KPI 카드와 캠페인별 트렌드 차트.
  [사용자 지정]으로 위젯을 직접 구성할 수 있습니다 (→ [캠페인·그룹 대시보드](/claire/dashboards#캠페인캠페인-그룹-대시보드))
- **캠페인** — 이 그룹에 속한 캠페인 목록 (플랫폼 · 기간 · 지표 집계 · 상태).
  [캠페인 가져오기]로 매체 연동 화면으로 이동해 캠페인을 더 불러옵니다.
- **이력** — 변경 이력

그룹에 어떤 캠페인을 넣을지는 목록 행 메뉴(⋮) 또는 상세 ⋮ 메뉴의 [수정] 화면에서
정합니다. 아직 그룹이 없는 캠페인을 추가하거나 속한 캠페인을 빼고 저장하면
반영되며, 캠페인 수정 화면의 **캠페인 그룹** 선택으로 다른 그룹에 옮길 수도
있습니다. 상세 ⋮ 메뉴의 [캠페인 그룹 비활성]으로 그룹을 비활성화합니다.

## 매체 연동 — 연결 위저드

**설정 → 플랫폼 연동**에서 [연결]을 누르면 4단계 안내
위저드가 열립니다. DV360, Google Ads, Meta, SA360, Kakao Moment를 지원합니다.
Naver GFA와 수동 업로드(Manual upload)는 목록에 보이지만 `사용할 수 없음`으로 표시되어
선택할 수 없습니다.

![플랫폼 연동 위저드](/img/claire/platform-connect.png)

1. **플랫폼 선택** — 연동할 매체를 고릅니다. 이미 연결된 플랫폼은 숨겨지고, 연동을 지원하지 않는 플랫폼은 흐리게 표시됩니다.
2. **인증** — 승인 버튼을 누르면 해당 매체의 로그인 화면으로 이동합니다.
   연동은 OAuth 방식이라 비밀번호나 토큰을 Claire에 직접 입력하지 않으며,
   인증이 끝나면 자동으로 다음 단계로 돌아옵니다.
3. **계정 선택** — 그 매체의 광고 계정 목록에서 가져올 계정을 고릅니다.
4. **캠페인 선택** — 계정의 캠페인 중 등록할 것을 골라 마칩니다.
   예전에 삭제했던 캠페인을 다시 고르면 복원 여부를 확인합니다.

Kakao Moment는 카카오 비즈니스 계정으로 인증하며, 광고 계정과 캠페인은 불러오지만
예산·기간 정보는 매체에서 제공하지 않아 비어 있습니다. 예산은 캠페인 수정에서
직접 입력할 수 있습니다.

Kakao Moment는 **광고 계정마다 인증 정보를 따로 보관**합니다. 계정 관리 화면에서
계정을 가져올 때 다른 매체와 달리 카카오 인증을 먼저 거친 뒤 계정
선택 화면으로 돌아오고, 거기서 고른 계정에 그 인증 정보가 저장됩니다. 그래서
나중에 다른 광고 계정을 인증해도 앞서 붙여 둔 계정의 수집은 끊기지 않습니다.
연동을 마친 뒤 광고 계정을 더 붙이려면 [연결]이 아니라 해당 매체 행 메뉴의
[관리]로 들어가세요.

연동을 마친 뒤에도 플랫폼 행 메뉴(⋮)의 [관리]에서 언제든 계정을 더 가져오거나
캠페인을 추가로 등록할 수 있습니다.

![플랫폼 계정 관리](/img/claire/platform-accounts.png)

:::caution 연동 해제 시 주의
플랫폼 행 메뉴의 [연결 끊기]를 누르면 그 계정으로 등록된 캠페인이 모두 비활성화되고
`연결 해제됨` 상태가 됩니다. 다시 쓰려면 재연동이 필요합니다.
:::

### 매체 연동이 안 될 때 — 플랫폼별 점검

연동은 매체 쪽 로그인·권한에 좌우되므로 Claire 화면보다 매체 계정 상태를 먼저
확인하세요. 한 번 연결된 플랫폼의 토큰은 매체 정책이 바뀌어도 유지되며, 아래 문제는
주로 **새로 연결하거나 [재인증]할 때** 생깁니다.

**Google (Google Ads · DV360 · SA360)**

- **패스키 인증 루프** — 2026년 8월 5일부터 Google Ads·API 로그인에 패스키가 순차
  의무화됐습니다. 승인 버튼을 누른 뒤 Google이 PC에서 휴대폰으로 패스키 인증을
  넘기는데, 휴대폰에 쓸 수 있는 패스키가 없으면 "사용할 수 있는 패스키가 없습니다"가
  반복됩니다. 개인 Gmail과 달리 **회사 Workspace 계정은 사용자 개인이 끌 수 없고**,
  Workspace 관리자가 관리자 콘솔의 비밀번호 없는 로그인(패스키) 설정에서 조직 단위로
  "비밀번호 없이 로그인"을 해제해야 비밀번호 로그인으로 진행됩니다. 급하면 같은
  PC에서 먼저 패스키를 하나 만들어 두거나, 인증 화면의 [다른 방법 시도]로 비밀번호를
  고르세요.
- **브라우저에 Google 계정이 여러 개 로그인돼 있을 때** — 계정 선택 화면에서 광고
  계정 권한이 있는 계정을 골라야 합니다. 엉뚱한 계정으로 인증하면 다음 단계에 "가져올
  계정이 없습니다"만 나옵니다. 계정이 섞여 꼬이면 시크릿 창이나 별도 Chrome
  프로필에서 다시 연결하세요.
- **"Google에서 확인하지 않은 앱" 경고** — Claire의 Google 앱 심사가 진행 중인
  동안 동의 화면에 뜰 수 있습니다. [고급] → [Claire Insight(으)로 이동]을 누르면 계속
  진행됩니다.
- **계정 목록이 비어 있음** — 인증한 Google 계정에 Google Ads 계정(또는 MCC) 접근
  권한이 없는 경우입니다. 매체 쪽에서 해당 사용자에게 광고 계정 권한을 먼저 주세요.
  DV360은 광고주 사용자 권한과 Bid Manager 보고서 권한이 모두 필요합니다.

**Meta**

- **Facebook 2단계 인증** — 보안 키(USB)만 등록된 계정은 보안 키를 꽂을 수 있는
  PC에서만 인증이 끝납니다. 미리 인증 앱이나 SMS 같은 다른 2단계 수단을 추가해
  두세요.
- **광고 계정이 너무 많이 보임** — Facebook 사용자가 접근 가능한 모든 비즈니스의
  광고 계정이 나옵니다. 전체 선택하지 말고 이 팀의 계정만 고르세요. 광고 계정이 아예
  없으면 비즈니스 관리자에서 그 사용자에게 광고 계정 역할을 먼저 부여해야 합니다.
- **재인증 필요** — Meta 토큰은 주기적으로 만료됩니다. 플랫폼 연동 상태가 재인증
  필요로 바뀌면 [재인증]만 하면 되고 계정·캠페인은 그대로 유지됩니다.

**Kakao Moment**

- 카카오 비즈니스 계정으로 인증하며 **광고 계정마다 인증을 따로** 보관합니다. 계정을
  더 붙일 때는 [연결]이 아니라 행 메뉴의 [관리]로 들어가세요 (위 참고).
- 예산·기간은 매체가 주지 않으므로 비어 있는 게 정상입니다. 캠페인 수정에서 직접
  입력하세요.

**공통**

- 매체 로그인은 **팀원마다 따로** 합니다. 다른 팀원이 연결한 플랫폼은 그 사람 계정의
  권한으로 수집되므로, 그 사람이 매체 권한을 잃거나 팀을 떠나면 수집이 멈춥니다.
  이때는 남은 팀원이 같은 플랫폼을 자기 계정으로 다시 연결하세요.
- [연결 끊기]는 그 계정으로 등록된 캠페인을 모두 `연결 해제됨`으로 바꿉니다. 인증만
  갱신하려면 끊지 말고 [재인증]을 쓰세요.

## 캠페인 관리

등록된 캠페인은 캠페인 그룹 상세의 **캠페인 탭**과 **운영 → 캠페인 →
캠페인**(전체 목록)에서 관리합니다. 우측 상단의 **내 데이터 / 팀 전체** 전환으로
내가 연동한 매체 계정의 캠페인만 볼지, 팀의 모든 캠페인을 볼지 고릅니다
(→ [플랫폼 연동](/claire/settings#플랫폼-연동--매체-연동)). 전체 목록 상단의 필터 칸에 조건식을
쓰고 [적용]을 누르면 목록이 좁혀집니다. 입력 중에 필드와 값이 자동 완성되고,
표의 캠페인 그룹·플랫폼·상태 칸에 마우스를 올리면 그 값을 필터로 바로 추가할
수 있습니다. 필터는 주소(URL)에 담기므로 링크를 복사해 공유할 수 있습니다.

```
campaign.status: enabled AND platform: meta
campaign_group.name: "브랜드A" AND NOT campaign.name: *테스트*
campaign.budget.daily >= 100000
```

값은 정확히 일치해야 하며, 부분 일치는 `*브랜드*`처럼 별표를 씁니다. 쓸 수 있는
필드는 `campaign.name` / `.code` / `.status`(enabled · disabled · disconnected), `campaign_group.name` / `.code`(`none`이면 그룹 없음), `platform`,
`campaign.budget.daily` / `.total`, `campaign.period.start` / `.end`이며,
`AND` `OR` `NOT`과 괄호로 조합합니다. 캠페인 그룹 목록에도 같은 필터 칸이 있습니다.
조건식이 잘못되면 목록이 "데이터 없음"으로 비어 보이니 문법을 확인하세요.

![전체 캠페인 목록](/img/claire/campaigns-list.png)

목록에는 이름 · 캠페인 그룹 · 플랫폼 · 기간(시작일/종료일 정렬) · **지출 (최근 7일) ·
예산 소진 · 어제 지출 / 일 예산 · KPI(달성/전체) · 알림** · 상태 열이 있고, [열 선택]에서
노출 · 클릭 · CTR · CPM · CPC · 전환 · ROAS(최근 7일) 같은 열을 더 켜거나 끌 수 있습니다.

목록 상단 [캠페인 가져오기]를 누르면 연동된 매체를 골라 캠페인을 더 불러올
수 있습니다. 재인증이 필요한 매체는 여기에서도 [재인증]으로 표시됩니다.
[데이터 업로드]는 연동되지 않은 매체의 실적을 고정 양식으로 올리는 화면입니다
(→ [성과 확인](/claire/performance#성과-데이터-수집)).

### 여러 캠페인 한꺼번에 처리하기

목록 맨 왼쪽 체크박스로 캠페인을 고르고 상단 **작업 (N)** 메뉴를 열면
선택한 캠페인에 한꺼번에 적용할 수 있습니다. 머리글 체크박스는 현재 페이지에서
고를 수 있는 캠페인을 모두 선택하며, 페이지를 넘겨도 선택은 유지됩니다.

| 메뉴 | 하는 일 |
|---|---|
| **선택 캠페인 재수집** | 선택한 캠페인의 성과를 지정한 기간으로 다시 수집 (→ [성과 확인](/claire/performance#성과-데이터-수집)) |
| **일괄 편집** | 선택한 캠페인의 **캠페인 그룹 · 일일 예산 한도 · 총 예산**을 한 번에 수정. 체크한 항목만 바뀝니다 |
| **활성화** / **비활성화** | 캠페인 활성화 / 비활성화 |
| **연결 끊기** | 매체 연결 해제 |

![일괄 편집](/img/claire/campaigns-bulk-edit.png)

- 캠페인 수정 권한이 없으면 체크박스가 잠깁니다. 활성화는 비활성 캠페인만,
  비활성화는 활성 캠페인만 고른 경우에 눌립니다. 재수집과 연결 끊기는 고른
  캠페인이 모두 활성이고 매체에 연결돼 있어야 눌립니다.
- 활성화 · 비활성화 · 연결 끊기는 처리 후 **실패한 캠페인만 선택 상태로 남아**
  바로 다시 시도할 수 있습니다. 재수집은 창 안에서 재시도하며, 창을 닫으면
  선택이 모두 풀립니다.

캠페인 상세에는 **대시보드 · 상세 정보 · 알림 · 이력** 탭이 있습니다
(DV360은 **게재 항목** 탭, Meta는 **소재** 탭 추가). 대시보드 탭은 KPI 카드와 성과 추이
차트를 보여주고([성과 확인](/claire/performance)), 상세 정보 탭은 매체 연결
정보(URN, 연결 계정, 플랫폼 캠페인 ID, 예산, 캠페인 목표, 업종, 기간, 지표 수집 주기와 다음 수집
시각)를 보여줍니다. 알림 탭은 이 캠페인에 걸린 알림 규칙과 최근 알림을, 이력 탭은
변경 이력을 보여줍니다. Meta 캠페인의 **소재** 탭은 기간(최근 7 · 14 · 30 · 90일) 동안의
소재(광고)별 합계를 표로 보여주며 열 제목을 눌러 정렬합니다. 90일보다 오래된 기간은
볼 수 없습니다. 캠페인 기간(시작일·종료일)은 매체에서 가져온 값이라
Claire에서 고칠 수 없습니다. URN 옆 복사 버튼으로 식별자를 복사할 수 있고,
열려 있는 탭은 주소(URL)에 저장되므로 특정 탭을 바로 가리키는 링크를 동료에게
