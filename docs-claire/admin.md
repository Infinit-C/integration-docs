# 사용자·권한 관리

사이드바의 **Security** 섹션은 조직 관리자용 메뉴입니다. 조직에 누가 들어올 수
있는지, 각자 어떤 권한을 갖는지, 외부 시스템의 API 접근은 어떻게 허용할지를
여기서 관리합니다.

## Users — 사용자

조직 구성원 목록입니다. [Invite user]로 이메일 초대를 보내거나 [Add user]로
계정을 직접 추가합니다. 목록에서 각 사용자의 상태와 마지막 로그인 시각,
소속 그룹을 확인할 수 있습니다.

![Users](/img/claire/security-users.png)

## User Groups · Policies — 그룹과 권한 정책

- **User Groups** — 사용자를 팀이나 역할 단위로 묶습니다. 권한은 개인보다
  그룹에 부여하는 편이 관리하기 쉽습니다.
- **Policies** — 접근 범위(Scope)를 정의하는 권한 정책입니다. 만들어 둔 정책을
  사용자 그룹이나 API 키에 연결해서 접근을 제한합니다.

## API Keys

외부 시스템에서 Claire API를 호출할 때 사용하는 조직 API 키를 발급합니다.

![API Keys](/img/claire/api-keys.png)

- [Generate API key]로 발급하며, 조직당 최대 5개까지 만들 수 있습니다.
- 키마다 정책(Policies)을 연결해 권한 범위를 좁힐 수 있습니다. 필요한 최소
  권한만 부여하는 것을 권장합니다.
- 목록에 만료일과 마지막 사용 시각이 표시되니, 쓰지 않는 키는 정리하세요.

:::warning
API 키의 전체 값은 발급하는 순간에만 보여줍니다. 안전한 곳에 보관하고
코드 저장소나 문서에는 남기지 마세요. 유출이 의심되면 바로 폐기하고 재발급하면 됩니다.
:::
