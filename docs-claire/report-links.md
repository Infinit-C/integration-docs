# 보고서 링크 (외부 공유)

**보고서 링크**는 캠페인 또는 캠페인 그룹의 성과를 Claire 계정이 없는
클라이언트·파트너에게 읽기 전용 웹 페이지로 공유하는 기능입니다. 링크를 받은
사람은 로그인 없이 만료일까지 보고서를 볼 수 있고, 켜 두었다면 보고서 내용에
대해 AI에게 질문도 할 수 있습니다. 매체 원가나 마진 같은 내부 비용은 포함되지
않습니다.

## 링크 만들기

캠페인 상세 또는 캠페인 그룹 상세 우상단의 [보고서 링크]를 누르면 설정
대화상자가 열립니다.

![보고서 링크 대화상자](/img/claire/report-link-dialog.png)

| 항목 | 내용 |
|---|---|
| **제목** | 받는 사람 화면의 제목 (예: 월간 성과 보고서) |
| **리포트 메모** | 보고서 맨 위 **인사이트** 칸에 그대로 표시되는 안내 문구. 비워 둘 수 있습니다 |
| **지표** | CPC · CPM · CPV · CTR · VTR · 클릭 · 완료 시청 · 노출 · 동영상 재생 · 지출 중 선택 (기본 CTR · 클릭 · 노출 · 지출) |
| **구성** | **요약**(지표 카드) · **일별 추이**(지표별 차트와 일별 표) · 그룹 링크는 **캠페인별**(캠페인별 합계 표) |
| **소재 성과 포함** | 켜면 기간 동안의 소재(광고)별 성과 표가 보고서에 들어갑니다. **정렬 기준**(위에서 고른 지표 중 하나)과 **개수**(상위 5 · 10 · 20개)를 고릅니다. 썸네일이 있는 소재는 이미지도 함께 보입니다 |
| **리포트 관련 AI 채팅 활성화** | 받는 사람이 보고서에 대해 질문할 수 있게 합니다. 답변은 이 보고서의 숫자만 근거로 하고, 링크마다 하루 10개까지 질문할 수 있습니다 |
| **함께 보기** | 한 그래프에 함께 그릴 지표를 2~4개 고릅니다. 지표마다 눈금을 따로 잡습니다 |
| **기간** | 최근 7일 · 14일 · 30일, 또는 **기간 지정**으로 시작일·종료일 입력 |
| **만료** | 7일 · 30일 · 90일 · 365일 |

[링크 만들기]를 누르면 "링크를 만들었습니다" 알림과 함께 링크 주소가 **그 자리에서 한 번만** 표시됩니다. [복사]로
복사해 두세요. 대화상자를 닫은 뒤에는 주소를 다시 볼 수 없으니, 잃어버렸다면
링크를 끊고 새로 만들어야 합니다.

:::caution
링크를 아는 사람은 누구나 열 수 있습니다. 메신저·메일로 전달할 때 수신자를
확인하고, 더 이상 공유할 필요가 없으면 [링크 끊기]로 바로 끊으세요.
:::

## 받는 사람이 보는 화면

링크를 열면 Claire 로그인 없이 아래 구성의 보고서 페이지가 열립니다. 휴대폰
화면에도 맞춰 표시됩니다.

![공유 보고서 페이지](/img/claire/report-share-page-full.png)

- 제목 · 대상 캠페인(그룹) 이름 · 보고 기간과 **기준 시각**(마지막으로 데이터를 읽은 때)
- **인사이트** — 리포트 메모
- **요약 카드** — 고른 지표의 기간 합계. 캠페인 그룹 보고서는 직전 같은 길이 기간
  대비 변화율(▲ ▼)도 함께 표시합니다. 직전 기간 데이터가 더 적으면 비교를 생략합니다
- **일별 추이** — 지표별 일별 선 차트, **지표 함께 보기** 차트(함께 보기를 골랐을 때)
- **일별 성과** — 날짜별 표와 합계 행. 그룹 보고서는 **캠페인별** 표가 추가됩니다
- **소재 성과** — 소재 성과 포함을 켰을 때, 정렬 기준 지표로 상위 N개 소재 표. 기간에
  수집된 소재 성과가 없으면 "이 기간에 수집된 소재 성과가 없습니다"로 표시됩니다
- 하단의 이용약관 · 개인정보처리방침 링크

AI 채팅을 켠 링크에는 우하단에 **[리포트에 대해 질문하기]** 버튼이 있습니다.
질문을 입력하면 이 보고서의 숫자만 근거로 답하며, 남은 질문 수("오늘 남은 질문
N개, 하루 10개까지")가 함께 표시됩니다. 답변은 AI가 만든 것이라 틀릴 수 있다는
안내가 붙습니다.

![공유 보고서의 질문 창](/img/claire/report-share-page-chat.png)

## 만든 링크 관리

같은 대화상자 아래 **만든 링크** 목록에서 링크마다 기간 · 상태(사용 중 / 끊김) ·
만료일 · **열람 수와 마지막 열람 시각**을 확인합니다. 끊었거나 만료된 링크는 기본으로
접혀 있고, [끊었거나 만료된 링크 N개 보기]를 누르면 펼쳐집니다.

- **받은 질문** — 받는 사람이 AI에게 한 질문과 답변을 날짜순으로 봅니다. 아직 없으면
  "아직 받은 질문이 없습니다"로 표시됩니다.
- **수정** — 제목·메모·지표·구성·소재 성과·기간·만료를 바꾸고 [변경사항 저장]을 누릅니다.
  링크 주소는 그대로이고, 받는 사람이 다음에 열 때부터 바뀐 설정이 적용됩니다.
- **링크 끊기** — 확인 후 즉시 끊깁니다. 받는 사람에게는 "보고서를 열 수 없습니다.
  보고서 링크가 만료되었거나 더 이상 사용할 수 없습니다."가 표시됩니다. 끊은 링크는
  **끊김** 상태로 접힌 목록에 남으며 다시 살릴 수 없습니다.

캠페인 그룹 링크의 캠페인 구성은 링크를 만들 때 기준으로 고정됩니다. 그룹에
캠페인을 더 넣었다면 링크를 새로 만드세요.
