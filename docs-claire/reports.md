# 보고서 내려받기

**모니터링 → 보고서**에서 캠페인 성과를 표 형태의 파일(CSV · XLSX)로
뽑습니다. 어떤 열(구분 기준)과 지표를 어떤 기간·단위로 볼지를 정한 보고서 정의를 만들어
두고, 필요할 때 실행해 파일을 내려받습니다.

![보고서](/img/claire/reports.png)

## 보고서 정의 만들기

[새 보고서]를 누르면 6단계 안내 화면이 열립니다. 각 단계는 [계속]으로 넘어갑니다.

1. **정의** — 이름, 세부 분류(누적 · 매월 · 매주 · 매일 · 시간별), 열로 쓸
   구분 기준(캠페인 그룹 이름/코드, 캠페인 이름/코드/시작일/종료일, 플랫폼,
   플랫폼 계정), 지표(기본 지표·수식)를 고릅니다. 고른 순서가 열 순서입니다.
2. **날짜** — 기간과 시간대. 어제 · 최근 7/30/60/90일 · 지난주 · 지난달 ·
   이번 달/분기/연도 같은 상대 기간 또는 직접 지정.
3. **필터** — 캠페인 그룹 · 캠페인 · 플랫폼별로 포함/제외 조건을 겁니다.
   비워 두면 전체 데이터입니다.
4. **전달** — 수신 이메일을 고릅니다 (이메일 채널로 등록된 주소 중 선택).
5. **출력** — CSV · XLSX · 서식 적용 XLSX.
6. **예약** — 자동 실행 예약(한 번 · 매일 · 매주 · 매월, 분 단위는
   00 또는 30). 켜 두면 예정 실행 시각 5개가 미리 표시됩니다.

## 실행과 다운로드

목록의 **보고서 정의** 탭에서 실행 아이콘을 누르면 **생성된 보고서** 탭으로
이동하고 실행이 큐에 들어갑니다(대기 → 실행 중 → 완료). 완료되면 행의
다운로드 아이콘으로 파일을 받습니다. 파일명은 `보고서이름-실행시각` 뒤에
형식에 맞는 확장자(.csv 또는 .xlsx)가 붙습니다. 목록의 **다음 실행 · 일정**
열에서 예약 상태를 확인할 수 있습니다.

:::note
현재 버전에서는 실행 결과를 화면에서 내려받는 방식이 기준입니다. 예약 실행과
이메일 발송 설정은 저장되지만 아직 자동으로 동작하지 않으니, 정기 발송이
필요하면 [맞춤 요약 보내기](/claire/custom-summaries)를 이용하세요.
:::
