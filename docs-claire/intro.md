# Claire

Claire는 캠페인 성과 모니터링과 대화형 분석을 한곳에서 제공하는 서비스입니다.
여러 매체에 흩어진 캠페인을 연결해 두면 성과 지표가 자동으로 수집되고,
KPI 달성 현황이 추적되며, 그 데이터를 이미 알고 있는 Claire에게 바로
질문할 수 있습니다.

캠페인 연결부터 질문까지, 전체 흐름은 아래 1분 영상에 담겨 있습니다.

## 주요 기능

- **캠페인 통합 관리** — DV360, Google Ads, Meta, SA360 캠페인을 광고주 단위로 묶어 한 화면에서 관리합니다.
- **성과 수집·추적** — 노출, 클릭, 전환, 비용 같은 핵심 지표를 매체에서 수집해 추이로 보여줍니다.
- **KPI 목표 관리** — 캠페인마다 CTR 하한, CPC 상한 같은 목표를 정해 두고 달성 여부를 확인합니다.
- **대화형 분석** — 캠페인 화면에서 채팅을 열고 "이번 주 성과 어때?"라고 물어보면 실제 데이터를 근거로 답을 받습니다.
- **알림** — KPI 이탈 같은 주요 이벤트가 생기면 지정한 채널로 알려줍니다.

## 핵심 개념

| 개념 | 설명 |
|---|---|
| **Campaign Group** | 광고주·브랜드 단위의 묶음입니다. 캠페인이 이 아래에 속합니다. |
| **Campaign** | 매체 플랫폼의 실제 캠페인과 1:1로 연결되는 단위입니다. 성과 수집, KPI, 대화가 모두 여기서 이뤄집니다. |
| **Metric / Formula** | 수집하는 기본 지표(노출·클릭·비용 등)와 그것으로 계산하는 공식(CTR·CPC·ROAS 등)입니다. |
| **KPI Rule** | "CTR은 얼마 이상"처럼 방향이 있는 목표 규칙입니다. 캠페인별 목표값의 뼈대가 됩니다. |
| **Chat** | 해당 캠페인의 정보를 알고 있는 Claire와의 대화입니다. 이력은 [My Chats](/claire/chat)에 남습니다. |
