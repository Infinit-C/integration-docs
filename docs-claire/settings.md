# 팀 설정과 알림

## 팀 설정

**설정 → 팀 설정**에서 팀(조직) 정보를 관리합니다. 우측 상단
계정 메뉴의 **팀 설정**으로도 같은 화면이 열립니다.

![팀 설정](/img/claire/organization-settings.png)

탭이 두 개입니다.

- **내 팀** — 계정 URN(복사 가능), 팀 이름·설명. 고친 뒤 [변경사항 저장]을 누릅니다.
  아래 **위험 구역**의 [내 팀 삭제]는 팀의 사용자·캠페인·연동을 모두 비활성화하므로
  주의하세요.
- **채팅 설정** — Claire 대화 문맥의 공유 범위 (→ [대화 문맥 공유 범위](/claire/chat#대화-문맥-공유-범위))

## 플랫폼 연동 — 매체 연동

팀에 연동된 매체 플랫폼을 한곳에서 관리합니다. [연결]로 새 플랫폼을
연동합니다(DV360 · Google Ads · Meta · SA360 · Kakao Moment). 연동된 플랫폼은
행 메뉴 [관리]에서 광고 계정·캠페인을 불러오거나 [연결 끊기]로 해제합니다. 연동 절차는
[캠페인 연결](/claire/campaigns#매체-연동--연결-위저드) 문서를 보세요.

매체 로그인은 **팀원마다 따로** 합니다. 목록의 **연결한 사람** 열에 누가 자기 매체
계정으로 연동했는지 표시되고, 화면 우측 상단의 **내 데이터 / 팀 전체** 전환으로
캠페인·대시보드를 내가 연동한 것만 볼지 팀 전체를 볼지 고릅니다. 다른 사람이 연동한
플랫폼을 끊으려면 그 매체에 대한 관리 권한이 있어야 합니다.

![플랫폼 연동](/img/claire/platform-integrations.png)

:::caution 재인증 필요
매체 쪽에서 인증이 만료되거나 취소되면(현재 Meta 토큰 만료 시) 상태가
`연결됨` 대신 **재인증 필요**로 바뀌고, 그동안 이 매체의
캠페인은 수집과 불러오기가 멈춥니다. [재인증]을 눌러 연결 위저드에서
다시 인증하면 기존 계정·캠페인 그대로 수집이 재개됩니다. 계정 관리는 재인증
전까지 숨겨집니다.
:::

## 알림 — 알림 규칙

**모니터링 → 알림**에서 [알림 생성]을 눌러 알림 규칙을 만듭니다. 조건을 벗어나면
지정한 채널(이메일·Slack)로 알림이 가고, 발생 이력은 **알림 기록**에 쌓입니다.
목록 위의 요약 카드로 전체 알림 · 알림 발생 · 데이터 없음 · 꺼짐 개수를 한눈에 보고,
목록에서는 규칙마다 조건 · **최근 값** · **기준값** · 상태를 나란히 확인합니다.

![알림](/img/claire/alerts.png)

알림 생성 화면은 다섯 단계입니다.

1. **대상 선택** — 캠페인 그룹과 대상 범위(캠페인 그룹 전체 또는 특정 캠페인,
   DV360은 게재 항목 단위)
2. **확인할 지표 선택** — 지표 A, B, …를 추가합니다. 캠페인의 KPI 목표,
   일일 예산 소진율, 원지표, 수식 중 고르며 여러 지표를 계산식으로 조합할 수 있습니다
3. **집계 기간 설정** — 어느 구간의 데이터로 값을 계산할지 (아래 참고)
4. **알림 조건 설정** — 확인할 지표 · 조건(이상/이하 등) · 기준값. [조건 추가]로
   여러 조건을 "모두 충족" 또는 "하나라도 충족"으로 묶고, **고급 알림 조건**에서
   연속 횟수 · 정상 복귀 · 반복 알림을 정합니다. [현재 값으로 확인]을 누르면
   저장 전에 지금 수집된 값으로 조건 충족 여부를 미리 봅니다
5. **알림 받기 설정** — 알림 이름, 중요도(정보 · 주의 · 심각), 받는 사람(알림 채널 그룹)

### 집계 기간과 데이터 없음

규칙의 **3. 집계 기간 설정** 단계에서 평가값을 계산할 구간을 정합니다.
규칙 안의 모든 지표가 같은 구간을 씁니다.

| 항목 | 선택지 | 설명 |
|---|---|---|
| **집계 기간** | 최근 N시간 · 오늘 지금까지 · 이번 달 지금까지 · 전체 기간 | 평가 시점에서 N시간 거슬러 보기 / 오늘 0시부터 / 이달 1일부터 / 수집된 전체 |
| **집계할 최근 시간 (시간)** | 1~2160시간 | 최근 N시간일 때만 입력 (기본 24시간) |
| **집계 방식** | 기간 합계 · 평균 · 최소 · 최대 | 합계는 구간의 원지표를 합친 뒤 수식을 계산(CTR은 총 클릭/총 노출), 나머지는 수집 시점별 값의 평균·최소·최대 |
| **확인 주기 (분)** | 30~1440분 | 최소 평가 간격 (기본 30분). 수집 주기를 바꾸지는 않습니다 |
| **데이터 반영 대기 시간 (분)** | 0~10080분 | 매체 데이터 반영 지연을 감안해 구간 끝을 뒤로 미룸 (기본 60분) |
| **시간대** | IANA 이름 | 오늘·이번 달 기준의 날짜 경계 |
| **데이터가 없을 때** | 상태 유지, 알림 없음 · 상태 유지, 데이터 없음 알림 | 구간에 데이터가 없을 때의 동작 (기본은 알림 없음) |

- **새로 만드는 규칙의 기본값은 "최근 24시간 합계, 60분 대기"**입니다. 예를 들어
  13:00 평가는 어제 12:00부터 오늘 12:00 직전까지의 데이터로 계산합니다.
- 지출·노출처럼 계속 커지는 지표에 전체 기간으로 상한을 걸면 캠페인이
  오래될수록 언젠가 걸리게 되니, 최근 N시간으로 두거나 **일일 예산 소진율**
  지표를 쓰세요.
- 구간에 데이터가 없으면 0으로 보지 않고 **데이터 없음**으로 기록합니다. 상태는
  그대로 유지되고 위반·복구 연속 횟수만 초기화되며, 복구로 치지도 않습니다.
  "상태 유지, 데이터 없음 알림"을 고르면 채널로 데이터 없음 알림도 갑니다.
  측정값이 0인 것은 정상 데이터입니다.
- 목록 행 메뉴의 [평가 기록]에서 평가 시각, 구간, 결과(정상 · 알림 발생 ·
  데이터 없음), 지표별 수치를 확인할 수 있습니다.

알아두면 좋은 동작:

- 평가는 5분마다 도는 정기 평가와 자동 성과 수집 직후에 실행되며, 규칙마다
  확인 주기가 지났을 때만 실제로 계산합니다. [지금 수집]으로 수동
  수집한 데이터는 그 자리에서 평가되지 않고 다음 정기 평가에 반영됩니다.
- 규칙을 **수정하면 위반·복구 카운트가 초기화**되어 처음부터 다시 셉니다.
- 규칙 삭제는 비활성화한 뒤에만 가능합니다.
- 예산 소진율 알림은 캠페인에 일일 예산 한도가 설정돼 있어야 만들 수 있고,
  기준값은 0~100%만 입력할 수 있습니다. 지출은 Meta · Kakao Moment는 Spend,
  그 외 매체는 Media cost 지표로 계산합니다.
- 기준값 칸은 천 단위 쉼표가 붙어 표시되고, 화면의 지표 값은 소수점
  둘째 자리까지만 보여줍니다.
- **알림 기록**의 이벤트 종류는 알림 발생 · 정상 복귀 · 반복 알림 · 데이터 없음이고,
  **전달** 열에서 채널 전송 결과(전송됨 · 실패 · 채널이 없습니다)를 확인합니다.
  캠페인 상세의 **알림** 탭에서도 그 캠페인에 걸린 규칙과 최근 알림을 볼 수 있습니다.

## 알림 채널 그룹

알림을 받을 수신 그룹을 관리합니다. 알림 규칙이나 [맞춤 요약](/claire/custom-summaries)의
받는 사람으로 지정해 두면 이 그룹의 채널로 발송됩니다. [알림 채널 그룹 추가]로
만들며 유형은 두 가지입니다.

- **이메일(EMAIL)** — 그룹을 만들면서 수신 주소를 등록합니다.
- **Slack(SLACK)** — Slack 워크스페이스에 봇을 설치해서 연결합니다. 공개 채널은
  봇이 자동 참여하고, **비공개 채널은 봇을 먼저 초대해야** 선택할 수 있습니다.

그룹 상세에서 [채널 추가]로 채널을 더 넣고, [이름 변경] · [삭제]로 그룹을
관리합니다. Slack 그룹은 워크스페이스만 연결하고 채널을 하나도 넣지 않으면
알림 기록의 전달 열에 "채널이 없습니다"로 남으니, 반드시 채널까지 추가하세요.
