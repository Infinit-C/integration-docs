# Claire와 대화하기

Claire의 중심 기능입니다. 캠페인 화면에서 채팅을 열면 **그 캠페인의 연결 정보와
성과 데이터가 컨텍스트로 주입된 상태**로 대화가 시작됩니다 — 캠페인 이름과 기간을
일일이 설명할 필요 없이 바로 질문하면 됩니다.

## 대화 시작하기

캠페인 상세 화면의 **우하단 채팅 버튼**을 누르면 Claire Chat 패널이 열립니다.

![Claire Chat 패널](/img/claire/chat-panel.png)

- **Enter**로 전송, **Shift+Enter**로 줄바꿈.
- 패널 좌상단의 확장 버튼으로 전체 화면 대화로 전환할 수 있습니다.

이렇게 물어보세요:

- "최근 성과 요약해줘"
- "CTR이 왜 떨어졌지?"
- "지금 추세면 이번 달 KPI 달성 가능해?"

## 대화 이력

나눈 대화는 사이드바의 **My Chats**에 캠페인별로 저장됩니다. 언제든 다시 열어
이어서 질문할 수 있습니다. 조직 관리자는 **Operations → Chats**에서 조직 전체의
대화 목록을 볼 수 있습니다.

![My Chats](/img/claire/my-chats.png)
